# 🚀 Deployment Guide - Military Info Command Center

Military Info is a fully static client-side React SPA. It can be hosted on any static web host (Vercel, Netlify, GitHub Pages, Cloudflare Pages, S3, etc.). 

Since it supports **Keyless RSS Sourcing** and **In-App Key Configurations**, you do not need to configure any environment variables on the host platform! The site operates out-of-the-box using public RSS feeds.

---

## ⚡ Quick Deploy to Vercel (Recommended)

1. **Push your code to GitHub.**
2. Visit [vercel.com](https://vercel.com) and log in.
3. Click **Add New** → **Project**.
4. Import your GitHub repository.
5. Configure:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
6. *(Optional)* If you wish to embed default API keys, add Environment Variables:
   - Name: `VITE_NEWS_API_KEY` (Value: your NewsAPI key)
   - Name: `VITE_THENEWSAPI_KEY` (Value: your TheNewsAPI key)
7. Click **Deploy**.

---

## ⚡ Deploy to Netlify

1. Visit [app.netlify.com](https://app.netlify.com) and log in.
2. Select **Import from Git** or drag-and-drop the local `dist/` directory generated by `npm run build`.
3. Configure build settings:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
4. Click **Deploy Site**.

---

## ⚡ Deploy to GitHub Pages
Since credentials are local, the app is fully compatible with GitHub Pages:

1. Install the `gh-pages` dev dependency:
   ```bash
   npm install -D gh-pages
   ```
2. Update `vite.config.js` to set the base directory:
   ```javascript
   export default defineConfig({
     plugins: [react()],
     base: '/military-info/', // Set to your GitHub repository name
   })
   ```
3. Add deploy scripts to `package.json`:
   ```json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   ```
4. Deploy the build:
   ```bash
   npm run deploy
   ```

## 🔍 Pre-Deployment Verification Checklist
- [ ] Verify build compiles without errors: `npm run build`
- [ ] Confirm `.env` is listed in `.gitignore` (prevents secret commits)
- [ ] Test the production bundle locally: `npm run preview`
- [ ] Open the preview and confirm **Keyless Mode** correctly fetches the 21 RSS channels.
